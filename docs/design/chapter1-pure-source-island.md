## 2. 劇情大綱【新提案】

世界觀文件「待決定事項」中的這幾項，我都在此給出**建議答案**，你可以逐項否決：
島民文化、主角為何離開、第一個主要敵人、第一件重要遺物、第一章的衝突。

### 序：島上的日子（胎息村）

主角住在島上的聚落「胎息村」。島民以狩獵、汲取島上的「源水」維生，不太談論外面的世界——
他們知道有四片大陸，但那是「海的另一邊的事」。村長祈漪要主角先向獵人岩牙學習防身，因為近來林子裡的野獸變得焦躁。

### 第一幕：訓練與焦躁的林子（臍帶林道）

岩牙帶主角到林道狩獵，教玩家戰鬥基本功。順利完成後，汲水人汐帶來壞消息：
島民賴以為生的源泉，水色最近變得混濁。

### 第二幕：第一次異常（源泉洞）

主角進入源泉洞，遇到從沒見過的東西：身體長出多餘肢體、動作不自然的生物（第 1 層**畸變體**）。
洞底有一隻特別強壯的**菁英畸變體**，擊倒後在水源邊撿到一塊會發出微光、並讓主角手上的血管隨之跳動的碎片。
**這是主角第一次察覺自己與別人不同**（世界觀第二幕）。

### 第三幕前段：初胎遺跡

主角把碎片帶給祈漪。祈漪沉默許久，只說：「它該去的地方是遺跡。」並承認遺跡入口的封石只對「某種血」有反應。
遺跡內，守衛石像的**仿影**（第 2 層仿神者，模仿古代守衛的生物）攔住去路。擊敗它後，
主角找到**第一件重要遺物**「初胎之印」，與碎片合一、與主角共鳴。壁畫上刻著四片大陸的輪廓——**但沒有刻出這座島**。

### 第三幕：離開純源島（斷潮海岸）

主角回到村子，發現海岸擱淺了一艘**不屬於島上的渡船**：船身是金屬與骨骼拼成的造物，
帶著神掌之陸工坊的印記（暗示瓦爾坎，**不明說**）。船上沒有人，船頭卻指向同一個方向。
老舵（村裡的船匠）說它是遺跡甦醒的同一個夜晚擱淺的。祈漪要求主角帶著初胎之印搭船離開，
去弄清楚它為什麼只在「那天」出現。主角登船，**第一章結束**。

> 【新提案】**離開的理由 = 渡船自己抵達，加上長老的委託。** 備選方案：
> (B) 遺跡事件後源泉污染擴大，島民推舉主角去外面找原因；(C) 初胎之印被不明人物奪走，主角追出去。
> 方案 A（渡船）的優點是不需要新角色、能自然帶出神掌之陸與瓦爾坎，又沒有決定「為什麼是現在」的真正原因（保留謎團）。

### 這一章刻意留下的謎團（不解答）

- 為什麼這座島沒有被四神佔領。
- 為什麼遺跡壁畫沒有畫出島。
- 渡船是誰派來的、為什麼剛好在遺跡甦醒那晚抵達。
- 祈漪知道多少。

### 4.1 村長 祈漪

- **【你的決定】** 慈祥的老人，有智慧，心中藏著遺跡的祕密。
- **外貌**：身形瘦小而挺直，白髮在腦後盤成低髻，手上有常年編織與搗藥留下的老繭；腰間繫著一小串磨得發亮的貝殼，一緊張就會下意識撥弄。
- **說話方式**：語速慢，常用比喻，把話說到一半就停下來讓聽者自己想；稱呼主角時帶著疼愛，不用命令句，而是「你願不願意……」。
- **想要什麼**：讓島民平靜地過完日子；不希望主角被捲進「那些事」。
- **隱瞞的事**：知道遺跡的封石只對某種血反應，也隱約知道主角的來歷與神血有關。**但這章不說破**，只讓玩家察覺「祈漪早就知道」。
- **與主角的關係**：看著主角長大，像祖輩，但對主角的視線裡有一絲愧疚。
- **矛盾點（讓角色立體）**：祈漪的慈祥是真的，隱瞞也是真的；祈漪相信「不知道比較幸福」，這個信念在第一章末被渡船動搖。
- **示例台詞**
  - 初次見面：「又來看井水？別怕，水不會咬人……至少以前不會。」
  - 任務 3 前：「這塊碎片，你先握著。是不是……有點像在握一顆還沒睡著的心？」
  - 任務 4：「去吧。回來的時候，也許我就該把該說的話說完了。」
- **互動演變**：任務 1–2 期間只給建議；交出碎片後話突然變少；任務 3 完成後第一次主動說出「遺跡」以外的事（只暗示，不解釋）。

### 4.2 獵人 岩牙

- **【你的決定】** 壯年、獵人、使用弓箭與匕首、粗獷。
- **外貌**：肩寬、曬得黝黑，左臂有舊爪痕；背弓，腰間插兩把長短不一的匕首；鬍子隨便刮過，衣服縫補的針腳又大又歪。
- **說話方式**：聲音大、句子短，愛用「小子／丫頭」之類的粗話稱呼晚輩（稱呼不依主角性別決定）；批評很直接，但每次批評後面都跟著一個具體的改法。
- **想要什麼**：讓村裡的年輕人學會自保；不想再看到有人死在林子裡。
- **隱瞞的事**：近來林子裡的獸「眼神不對」，岩牙自己嚇了一跳，卻嘴硬說「只是餓了」。
- **與主角的關係**：像不太會表達關心的長輩或教官。
- **與玩法的呼應**：任務 1 教玩家用普攻與技能清掉林牙獸；岩牙示範的是「弓箭與匕首」的獵人形象，主角本身仍是近戰（**不代表會改變主角的武器**）。
- **示例台詞**
  - 任務 1 開始：「別拿那種眼神看我，劍舉高！野獸可不會等你想好。」
  - 完成後：「還行。比我年輕時差一點……就一點。」
  - 後期閒談：「那些獸的眼睛……算了，當我沒說。」

### 4.3 汲水人 汐

- **【你的決定】** 內向、矮小、靈活、觀察入微、女性。
- **外貌**：身形嬌小，動作輕快，總是赤腳或穿薄底鞋；肩上掛著竹製水桶與一個隨身的小布包，裡面裝著各種她收集的小東西（羽毛、碎陶片、顏色怪異的石頭）。
- **說話方式**：聲音小、句子不完整，常說到一半縮回去；但一談到她觀察到的細節（水的顏色、味道、鳥群的方向）就會突然變得流利精確。
- **想要什麼**：弄清楚水為什麼變了；她不想「被人看著」，所以大多數時候靠近就會先躲開視線。
- **隱瞞的事**：她比誰都早發現水的變化，卻因為不確定、怕被當成大驚小怪，拖了幾天才開口。
- **與主角的關係**：和主角算是比較放得開的同輩朋友；是少數能讓她放鬆說話的人。
- **與玩法的呼應**：任務 2 的「調查洞底的碎片」由她提供線索（「那個味道，像鐵，又像剛下過雨的泥土」）。
- **示例台詞**
  - 初次交談：「……啊。那個，水……不對勁。我、我不是亂說的，你聞聞看？」
  - 任務 2 回報後：「你的手……剛剛，和碎片一起，亮了一下。你沒發現嗎？」（**她是第一個點破的人**）
  - 閒談：「今天的鳥，都往同一個方向飛。」

### 4.4 船匠 老舵

- **【你的決定】** 脾氣火爆、矮人、抽雪茄。
- **設定說明**：世界觀文件沒有「矮人」這個種族，這是你新加入的設定。我把它當成「純源島上存在的一支矮人族群成員」處理，不替矮人族另外編造歷史；如果你想讓矮人只是一個極個別的存在，或與神掌之陸有淵源（比較合理的鋪陳，因為鑄神者瓦爾坎的領地以工坊聞名），請告訴我。
- **外貌**：身高只到多數人的胸口，但手臂粗壯、肩膀厚實；鬍鬚編成兩股，永遠叼著一支快燒到鬍子的雪茄；衣服上滿是焦痕與木屑。
- **說話方式**：每句話都像在吼；髒話用「龜孫、木頭腦袋」之類不傷人的詞；對自己手藝非常自負，但別人真心稱讚時會突然沉默、轉頭做事。
- **想要什麼**：把每條船都修到能用；最討厭「半吊子的活」。
- **隱瞞的事**：他一眼就看出渡船**不是島上造的**，材質（金屬與骨骼拼接）他從沒見過，卻不肯承認自己被難倒。
- **與主角的關係**：嘴上罵得最兇，卻是第一個把船板拍給主角檢查的人。
- **與玩法的呼應**：任務 4 的辨認渡船、登船的最後一步。
- **示例台詞**
  - 初見：「看什麼看！要修船就排隊，要偷懶就滾遠點！」
  - 面對渡船：「這船……見鬼了。這骨頭的接縫比我做過的任何東西都漂亮。**我他媽的不服。**」
  - 送別：「上去吧，木頭腦袋。別讓人家把我修的船板給整壞了。」

| 類型 | 例子 | 備註 |

## 6. 與目前程式的落差（要新做的系統）

目前遊戲只有單一固定地圖與單一玩家出生點。要完成上面的設計需要：

| 系統 | 現況 | 要做的事 |
| --- | --- | --- |
| 多地圖管理 | 只有 `dungeon.json`，寫死在 `Game` | 地圖註冊表、切換地圖（卸載／載入世界）、保留玩家與背包 |
| 地圖格式 | `layout` + 單一 `P` | 加入 `entrances`（具名入口）、`portals`（含條件）、`npcs`、`interactables`、`monsterGroups` |
| 傳送門 | 沒有（出口 `X` 只是標記） | 區域觸發＋條件＋切圖＋短暫黑幕 |
| NPC 與對話 | 沒有 | NPC 實體（站立、名牌）、互動、對話框 UI |
| 互動物 | 沒有 | 調查點（碎片、陷阱、渡船、封石） |
| 任務系統 | 沒有 | `QuestDef` 資料、任務狀態機、事件接線、任務紀錄 UI（J 鍵）與追蹤 HUD |
| 存檔 | 尚未做 | 存檔要含：目前地圖、玩家位置/入口、任務狀態與旗標、等級與經驗、背包與裝備 |
| 怪物資料 | 屍鬼／祭影／獵犬＋執政官 | 新增島上怪物定義（林牙獸、畸變體、水影、仿影），**先沿用現有佔位圖並換名稱與數值** |

**設計原則**：地圖、NPC、對話、任務全部走資料檔（JSON/TS 資料），邏輯用純函式並可單元測試
（任務狀態機、傳送門條件、地圖連通性檢查），渲染與 UI 不放進這些邏輯。
