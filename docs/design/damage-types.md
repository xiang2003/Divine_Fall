# 《神墜》傷害類型、計算與抗性規則

> 2026-10-16 由使用者提供的設計。這一頁最上面是**實作狀態**，下面是原文（只改了排版）。

## 實作狀態

共用的傷害模組在 [damage.ts](../../src/systems/damage.ts)，六種類型與規則常數在 [damageTypes.ts](../../src/data/damageTypes.ts)，測試在 [damage.test.ts](../../tests/damage.test.ts)（模組本身）與 [damageCombat.test.ts](../../tests/damageCombat.test.ts)（接進戰鬥）。

| 原文的實作順序 | 狀態 |
| --- | --- |
| 1. 六種傷害類型與技能基礎傷害 | ✅ 六種類型有固定識別值、名稱、顏色；技能與怪物有傷害類型（旋風斬、墜神震擊是物理，神罰之矢是神聖，連鎖閃電是雷電；怪物各有類型，見下） |
| 2. 傷害加成與更多傷害乘區 | ✅ 「增加」同類相加後乘一次，「更多」各自連乘；裝備詞綴可以給同類型增加傷害（目前沒有「更多」的來源，只有模組支援） |
| 3. 元素抗性與抗性上下限 | ✅ 上限 75%、下限 -100%，上限可以個別提高（要明確指定）；抗性降低（先扣、再套上限）與抗性穿透（套上限之後才扣）分開 |
| 4. 物理護甲減傷 | ✅ 護甲 ÷ (護甲 + 5 × 基準傷害)，上限 75%；護甲穿透在減傷前處理 |
| 5. 暴擊系統 | ✅ 暴擊率限制在 0–100%、倍率至少 100%、預設 150%；一次攻擊只擲一次暴擊；只有明確允許的攻擊會暴擊（玩家的攻擊與技能會，怪物與持續傷害不會） |
| 6. 燃燒、流血與腐化持續傷害 | ✅ 模組完成（`DotSet`：同名刷新不疊加、可設最大層數、受對應抗性、流血預設不吃護甲、不暴擊、小數餘額累積），**已由[異常狀態系統](status-effects.md)使用**（燃燒、流血、腐化侵蝕、中毒）；現有的中毒（毒箭、花妖毒霧）也走同一個系統，受腐化抗性影響 |
| 7. 傷害轉換與抗性穿透 | ⚠️ 轉換與穿透的計算完成並測試（只轉一次、總和超過 100% 會按比例縮小、轉換後的傷害用新類型的增加與防禦），但**還沒有任何裝備詞綴或技能提供轉換／穿透** |
| 8. 護盾、格擋、免疫與其他特殊機制 | ❌ 還沒做 |

### 這一版的選擇（原文沒有寫死的地方）

- **護甲的「基準傷害」**：原文寫「攻擊者等級對應基準傷害」。現在還沒有怪物等級，所以用 **8**（一級怪物的基準，和[等級系統規劃](level-system.md)的怪物傷害曲線 8 × 1.045^(等級 − 1) 一致）；等級系統做好之後，每一擊傳入攻擊者等級的基準即可（`baselineDamage(level)`，模組已經支援）。
- **這會改變原本的平衡**：以前的公式是 100 ÷ (100 + 護甲)，護甲 5 只減 5%；現在護甲 5 就減約 11%，護甲 40 減 50%。鎖子甲（護甲 12）加上詞綴比以前強很多，第一章會比較好打。平衡之後要重調。
- **進位**：每種類型各自四捨五入，總傷害是各部分的和（所以畫面上的數字、扣血、死亡判定是同一個數字）；有傷害的一擊至少是 1。
- **傷害數字的顏色**：依這一擊中最高的那種類型（物理維持原色，其他依表）。
- **玩家的傷害來源**：「攻擊屬性提供的傷害」就是現有的攻擊力（武器、等級、詞綴），當成技能的那種類型的基礎傷害，再乘技能倍率。

### 怪物與裝備

- 怪物新增 `damageType`、`armor`、`resist`（見 [monsters.ts](../../src/data/monsters.ts)）。例如：源泉凝膠與溺靈水妖是冰霜（兩者冰霜抗性 50%、怕雷電）；墮靈修士、腐靈花妖是腐化；晶翼蝠、初胎守望者是神聖；岩石魔像、斷劍巨像有護甲（巨像是鐵，怕雷電 -30%）。
- 裝備新增詞綴：**增加物理／雷電／神聖傷害**（武器、戒指、胸甲）與**冰霜／雷電／腐化／神聖抗性**（頭盔、胸甲、鞋子、戒指）。**火焰沒有詞綴**：遊戲裡還沒有任何東西會造成或使用火焰傷害，等有了再加。
- 精英「閃電」詞綴的額外一擊是雷電傷害（吃雷電抗性）。
- 背包的屬性欄會列出非零的「X 傷害增加」與抗性；物品比較提示也會顯示它們的變化。

## 一、核心傷害類型

遊戲初期規劃 6 種傷害類型。

| 傷害類型 | 英文識別 | 主要特色 |
|---|---|---|
| 物理傷害 | Physical | 直接攻擊、流血、破甲 |
| 火焰傷害 | Fire | 燃燒、爆發 |
| 冰霜傷害 | Cold | 緩速、凍結、碎冰 |
| 雷電傷害 | Lightning | 連鎖、感電、暴擊 |
| 腐化傷害 | Corruption | 侵蝕、防禦瓦解、腐化異常 |
| 神聖傷害 | Divine | 神性力量、淨化、特殊克制 |

傷害類型、異常狀態與暴擊機制分開設計。

## 二、傷害計算順序

一般直接傷害依照以下順序計算：

1. 計算技能基礎傷害。
2. 加入角色屬性與技能倍率。
3. 計算增加傷害與更多傷害修正。
4. 判定暴擊並套用暴擊倍率。
5. 套用目標對應的抗性或防禦減傷。
6. 計算最終傷害並扣除生命值。

### 基本公式

```text
基礎傷害 = 技能基礎傷害 + 攻擊屬性提供的傷害

傷害加成倍率 = 1 + 同類型增加傷害總和

傷害修正後 =
    基礎傷害 × 技能倍率 × 傷害加成倍率 × 更多傷害倍率

暴擊傷害 =
    傷害修正後 × 暴擊倍率（若觸發暴擊）

最終傷害 =
    暴擊傷害 × 防禦減傷倍率
```

說明：

- **增加傷害（Increased）**：同類加成相加後計算。
- **更多傷害（More）**：不同獨立乘區依序相乘。
- 未觸發暴擊時，暴擊倍率視為 1。
- 若攻擊包含多種傷害類型，必須將各類傷害拆開計算防禦，再加總最終傷害。

## 三、抗性規則

每種元素與特殊傷害各自擁有對應抗性。

| 傷害類型 | 對應防禦 |
|---|---|
| 物理 | 護甲 |
| 火焰 | 火焰抗性 |
| 冰霜 | 冰霜抗性 |
| 雷電 | 雷電抗性 |
| 腐化 | 腐化抗性 |
| 神聖 | 神聖抗性 |

### 抗性計算公式

```text
有效抗性 = 基礎抗性 + 抗性加成 - 抗性降低

有效抗性 = 限制在 -100% 至 75% 之間

抗性減傷倍率 = 1 - 有效抗性

抗性計算後傷害 = 原始傷害 × 抗性減傷倍率
```

規則：

- 初期抗性上限為 75%。
- 初期抗性下限為 -100%。
- 正抗性降低受到的傷害。
- 負抗性會增加受到的傷害。
- 抗性上限可以透過裝備、天賦或特殊效果提高，但必須明確標示。
- 抗性降低效果與抗性穿透應分開定義，避免重複計算。

範例：

| 火焰抗性 | 傷害減免 | 受到 100 點火焰傷害 |
|---:|---:|---:|
| -50% | -50% | 150 |
| 0% | 0% | 100 |
| 30% | 30% | 70 |
| 75% | 75% | 25 |

## 四、物理傷害與護甲

物理傷害使用護甲計算減傷，避免護甲與其他傷害抗性混用。

初期採用以下簡化公式：

```text
護甲減傷率 = 護甲 / (護甲 + 5 × 攻擊者等級對應基準傷害)

護甲減傷率最高為 75%

物理傷害 = 原始物理傷害 × (1 - 護甲減傷率)
```

說明：

- 護甲主要減免直接物理傷害。
- 流血等持續傷害是否受護甲影響，由該異常狀態單獨定義。
- 後續可依照敵人等級與傷害成長曲線調整公式中的係數。
- 護甲穿透應在護甲減傷計算前處理。

## 五、暴擊規則

```text
暴擊率 = 基礎暴擊率 + 暴擊率加成

實際暴擊率上限 = 100%

暴擊倍率 = 基礎暴擊倍率 + 額外暴擊傷害
```

初始建議：

- 基礎暴擊倍率：150%。
- 暴擊率最低為 0%，最高為 100%。
- 暴擊倍率至少為 100%。
- 暴擊只影響技能明確允許暴擊的傷害。
- 持續傷害預設不會暴擊，除非技能或裝備另有規則。

## 六、持續傷害規則

持續傷害應與直接傷害分開處理，避免重複觸發暴擊或技能命中效果。

| 狀態 | 傷害類型 | 初期規則 |
|---|---|---|
| 燃燒 | 火焰 | 持續造成火焰傷害 |
| 流血 | 物理 | 持續造成物理傷害 |
| 腐化侵蝕 | 腐化 | 持續造成腐化傷害 |
| 凍結 | 無直接傷害 | 控制敵人行動 |
| 感電 | 雷電相關 | 提供額外受傷效果或觸發連鎖 |

統一規則：

- 持續傷害具有獨立的基礎傷害、持續時間與每秒傷害。
- 持續傷害預設不觸發暴擊。
- 同名持續傷害預設刷新持續時間，不重複疊加傷害。
- 若技能具有疊層效果，必須明確設定最大層數與每層傷害。
- 持續傷害仍須套用對應傷害類型的抗性。

## 七、傷害轉換

傷害轉換用於建立特殊技能與裝備流派。

例如：

```text
50% 物理傷害轉換為火焰傷害
```

計算規則：

1. 先依照轉換比例拆分原始傷害。
2. 轉換後的傷害改用新傷害類型計算。
3. 物理部分使用護甲，火焰部分使用火焰抗性。
4. 同一份傷害不可被重複轉換或重複計算。
5. 轉換比例總和不得超過 100%，除非另有明確設計。

初期可先實作轉換架構，不必立即加入大量轉換詞綴。

## 八、統一計算原則

- 所有傷害計算集中於共用傷害系統，不在各技能內重複實作公式。
- 所有抗性與護甲規則由共用防禦計算模組處理。
- 傷害類型應使用固定識別值，例如 `physical`、`fire`、`cold`、`lightning`、`corruption`、`divine`。
- 顯示傷害數字、扣除生命值與死亡判定應使用同一份最終傷害結果。
- 免疫、護盾、格擋、反傷等特殊防禦機制應設計為可擴充模組。
- 每次調整傷害公式，都應同步更新單元測試。

## 九、初期實作順序

1. 六種傷害類型與技能基礎傷害。
2. 傷害加成與更多傷害乘區。
3. 元素抗性與抗性上下限。
4. 物理護甲減傷。
5. 暴擊系統。
6. 燃燒、流血與腐化持續傷害。
7. 傷害轉換與抗性穿透。
8. 護盾、格擋、免疫與其他特殊機制。

以上數值皆為初期設計基準，後續應依照角色等級、裝備成長、敵人血量與戰鬥時間進行平衡測試。
