# 第二章：中立大陸「滄玄洲」設計草案（2026-10-15）

離開初始島嶼後，第一個登陸的是**中立大陸**。這裡是《神墜》前期的主要探索區域，讓玩家先接觸大陸勢力、靈氣修行與裝備交易，再逐步揭開神主與四位子嗣的祕密。

## 滄玄洲

地勢遼闊、山脈綿延、古老宗門與凡人城鎮共存，靈氣充沛但各地濃度不一。表面上由多方勢力維持平衡，深處卻隱藏著古代遺跡與靈氣異變的祕密。

## 地圖一：迷霧海岸

**敘述**：主角初次登陸的沿海地帶，遍布礁石、濃霧、廢棄船骸與潮濕森林。部分區域殘留著奇異的靈氣痕跡，是進入大陸後的第一個歷練區。

**敵對生物**：

1. **荒林野狼**：成群出現、移動快速、撲咬攻擊、會從側面包抄玩家
2. **裂角野豬**：體型壯碩、衝刺撞擊、撞上障礙物後會陷入硬直
3. **溺靈水妖**：外形近似半透明的人形水生生物、從水中突襲、發射水刃攻擊
4. **沉船怨骸**：由船員遺骸與靈氣形成、移動緩慢、使用鏽蝕武器攻擊、死亡後可能爆發怨氣

## 地圖二：青藤古林

**敘述**：位於海岸內陸的廣闊森林，古樹參天、藤蔓纏繞、發光菌類遍布林地。森林深處存在古老石碑與遭到靈氣侵蝕的祭壇，似乎與大陸早期的修行文明有關。

**敵對生物**：

1. **青牙狼**：成群出現、快速撲擊、低血量時呼叫同伴
2. **藤甲猿**：身披藤蔓與樹皮、近戰重擊、能以雙拳捶地造成範圍傷害
3. **腐靈花妖**：外形為大型妖異花朵、遠程噴射毒粉、在地面留下持續傷害區域
4. **古木巡守者（Boss）**：由古樹與岩石構成的巨大守衛、揮動樹臂攻擊、召喚根刺造成範圍傷害

## 城鎮：青嵐鎮

**敘述**：位於青藤古林與斷劍山道之間的山腳城鎮，是附近修行者、商旅與獵人的聚集地。鎮內有交易市場、客棧、藥鋪與修行者聚集的任務場所，是主角登陸大陸後第一個能夠安心休整的據點。

| NPC | 身分 | 功能 | 設定 |
| --- | --- | --- | --- |
| 周伯 | 客棧老闆 | 城鎮情報 | 經營青嵐客棧，待人熱情、消息靈通。會向主角介紹附近地區的危險與近期發生的異常事件，提供初期探索任務。 |
| 沈青禾 | 藥鋪學徒 | 藥品與素材 | 熟悉山林草藥與靈植，個性沉穩、觀察敏銳。負責藥品交易與素材兌換，也會委託主角採集稀有靈草。 |
| 鐵山 | 鐵匠 | 裝備與強化 | 曾替修行宗門打造兵器，因某些原因隱居在青嵐鎮。負責裝備販售、修理與強化，偶爾能辨認出古代遺跡中的特殊素材。 |
| 顧長風 | 流浪修士 | 主線引導 | 曾在大陸各地遊歷，實力不明，習慣獨自在城外觀察靈氣流動。他察覺主角身上帶有與普通修行者不同的氣息，卻沒有立即點破。 |
| 林若棠 | 巡山司接待人 | 任務與懸賞 | 負責管理附近地區的除妖懸賞與探索委託。行事俐落、不喜歡空談，會依照主角的實力逐步開放更危險的狩獵任務。 |

## 地圖三：斷劍山道

**敘述**：連接沿海森林與大陸內陸的險峻山道，沿途有崩塌的石橋、古代戰場、廢棄哨站與斷裂的巨大石劍。傳聞此地曾發生一場修行者之間的古老戰爭。

**敵對生物**：

1. **山地刃狼**：移動迅速、以爪牙進行連續攻擊、擅長短距離突進
2. **流亡刀客**：手持破損長刀、近身連續斬擊、會使用短距離突進
3. **墮靈修士**：身穿破損長袍、遠程發射暗色靈氣彈、低血量時進入狂暴狀態
4. **斷劍巨像（Boss）**：由古代戰場的兵器與岩石凝聚而成、使用巨劍進行大範圍揮砍、蓄力後重擊地面
