# 第二章美術方向：暗色仙俠（黑暗奇幻）

2026-10-15 依使用者的意見訂定：第二章（滄玄洲）原本偏「歐式村莊 + 可愛小物」（綠草地、粉白條紋攤位、盆栽、木箱、淡青色的發光蕈、沙地上的亮木頭堆），
氣氛應該更偏**仙俠**，並帶入本作的基調**黑暗奇幻**。

## 一句話

**墜神之後的修仙世界：宗門、符籙、靈燈還在，但一切都已經荒廢、被污染，活著的人是在廢墟裡勉強過日子。**

## 要什麼

- **建築**：飛簷、深灰瓦、黑褐木構、石基座；屋簷下掛符紙、藥葫蘆、褪色的紅燈籠；石獅、牌坊、香爐、石燈。破損的瓦、殘缺的旗、裂開的石像。
- **符籙與封印**：黃紙符貼在門上、罈子上、樹上；封罈、骨灰罈、棺木。這是「這個世界怕什麼」的線索。
- **光**：**冷青色**的靈火（窗內、燈籠、發光的苔與蕈）是「靈氣」；**暖橙色**只給人活動的地方（鐵匠爐、石燈）。朱紅只做小點綴（燈籠、旗上的劍印、符上的印）。
- **地面**：深色青石板、腐葉與黑土、裂開的山岩、灰色礫灘；不要亮綠的草。
- **自然**：枯樹（掛符紙、鈴鐺、藤蔓、紅布條，不要有葉子）、插滿斷劍的劍塚、折斷的石柱、黑色礁石與白骨。
- **色調**：整張圖冷色、偏暗、降低飽和（見下面的調色），邊緣有暗角。

## 不要什麼（可愛的來源）

- 粉白或其他明亮顏色的條紋布篷、盆栽、整齊的木箱與木桶（歐式市集的樣子）。
- 圓潤、飽和的卡通形狀；淡青色、粉色的小蘑菇；亮木色的浮木；綠色的樹葉。
- 乾淨、完整、沒有歲月的東西。

## 各地圖的樣子

- **迷霧海岸**：灰礫灘，冷灰藍的霧；黑色礁石纏著鐵鍊與白骨；擱淺的破船、朽木板。
- **青藤古林**：黑褐腐土；密密麻麻的枯樹，掛著符紙、紅布條、鈴鐺、青色魂燈與藤蔓；長在骷髏與朽木上的灰綠蕈。
- **青嵐鎮**：青石板廣場；客棧、藥鋪、鐵匠鋪、巡山司、民宅都是飛簷深瓦；牌坊、石獅、香爐、石燈、殘旗、墓碑與白骨；攤位是破黑布棚；告示板上釘著獸骨與血手印；以枯樹圍成外牆；封罈取代木箱。
- **斷劍山道**：龜裂的暗山岩，藍灰色的舊石板路，暗石板色的裂紋懸崖；插滿斷劍的劍塚、折斷的雕花石柱。
