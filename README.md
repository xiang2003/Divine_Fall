# 神墜 Divine Fall

單人 2.5D 等角視角刷寶 ARPG（Three.js + TypeScript + Vite + React）。

> 世界曾由古老神祇統治。一場名為「神墜」的災變讓神明隕落，神性碎片散落各處……

**目前進度：Phase 5 進行中（已完成經驗與升級、多地圖、NPC 與對話、任務系統與完整的第一章「純源島」，可從出生一路玩到登上渡船；存檔、技能學習、R / T 技能與升級強化選擇尚未實作）。** 可以在地城裡移動、閃避、施放三個技能、與怪物和菁英戰鬥、挑戰三階段的 Boss、撿裝備、換裝；
但存檔、升級強化選擇、R / T 技能、出口與重新進場、音效與選單都**尚未實作**，還不是完整的遊戲。下方「開發進度」逐項標示實際狀態。

## 快速開始

需要 Node.js 20+（開發環境為 Node 24）。

```bash
npm install
npm run dev        # 開發伺服器
npm run typecheck  # TypeScript 型別檢查
npm test           # Vitest 單元測試
npm run build      # 型別檢查 + production build（輸出到 dist/）
npm run preview    # 預覽 production build
```

## 操作

| 輸入 | 功能 | 狀態 |
| --- | --- | --- |
| 左鍵（點擊 / 按住） | 走到點擊位置；按住則持續朝游標移動，地面會顯示金色標記 | ✅ |
| 右鍵（點擊 / 按住） | 朝游標方向揮擊，按住則連續揮擊。揮擊時角色會停在原地，且右鍵優先於左鍵移動 | ✅ |
| Space | 閃避：朝游標方向短距離衝刺，衝刺期間無敵（冷卻 1 秒） | ✅ |
| I 或 B | 開關背包（Esc 也可關閉） | ✅ |
| J | 開關任務紀錄（Esc 也可關閉） | ✅ |
| M | 開關世界地圖：每張地圖是一個方塊，連線表示傳送門相通；金框是你的位置，暗色是還沒去過，橘色虛線加鎖是尚未開通的路（滑鼠停在鎖上有原因）。Esc 也可關閉；對話中不能開 | ✅ |
| 點擊地上物品的名稱 / F | 走過去撿起；F 撿起身邊最近的一件 | ✅ |
| Q / W / E | 技能：Q 旋風斬（身邊範圍）、W 神罰之矢（穿透光矢）、E 墜神震擊（游標位置範圍＋暈眩） | ✅ |
| R / T | 技能 4、5 | ⏳ 已綁定，按下顯示「技能尚未解鎖」（Phase 5 隨升級解鎖） |
| F3 → F4 / F6 / F7 / F8 / F9 / F10 | 除錯（需先按 F3 開啟除錯模式）：F4 在腳邊掉落 4 件傳奇與 3 件稀有；F6 直接穿上 4 件傳奇；F7 回滿血並重生所有怪物（保留裝備）；F8 傳送到菁英區 → Boss 房（再按一次切換）；F9 直接升一級；F10 同時開 / 關林道通往遺跡的封石與村子通往海岸的路 | ✅ |
| 死亡畫面的「重新開始」按鈕 | 回到起點、血量回滿、怪物重新生成 | ✅ |
| F3 | 顯示碰撞輪廓、出生點、FPS 與座標 | ✅ |
| Esc | 暫停選單 | ⏳ 目前只用來關閉背包、任務紀錄、地圖與對話 |

鍵位集中在 [src/config/gameConfig.ts](src/config/gameConfig.ts)：鍵盤用 `KEYBINDINGS`（`KeyboardEvent.code`），滑鼠用 `MOUSE_BINDINGS`（0 左鍵 / 2 右鍵）。
移動只用滑鼠，因此 W 不再是移動鍵，WASD 不會移動角色。技能暫定 5 個（QWERT），最終數量於 Phase 4 決定。

## 重要設計決策

- **座標**：世界座標為格子單位（1 單位 = 1 格），+x 朝螢幕右下、+y 朝螢幕左下。圖塊為 64×32 的 2:1 菱形。
  遊戲邏輯只用世界座標，只有渲染時才投影到畫面。
- **深度排序**：所有材質關閉 depth test，順序完全由 `renderOrder = 圖層 × 1,000,000 + (x+y) × 100` 決定，
  其中 x、y 為精靈**腳底**的世界座標。圖層：地板 < 地面裝飾（陰影、出口）< 物件（牆、箱子、角色）< 前景。
- **碰撞獨立於圖片**：只由 `MapData` 的牆格與箱子足跡決定。移動以小步長前進後推出重疊，自然得到貼牆滑行。
- **佔位美術**：Phase 1 的圖像全部由程式即時繪製，避免在授權未確認前引入外部素材。替換方式與授權清單見 [ASSETS.md](ASSETS.md)。
- **Vite `base: './'`**：所有 URL 為相對路徑，同一份 build 可放在網站根目錄或 GitHub Pages 子路徑（`/<repo>/`）。
  執行期資源（地圖、素材）透過 `assetUrl()` 加上 base。
- **React 只負責 UI**：Game 以 `useSyncExternalStore` 對外發佈不可變快照（約每 0.25 秒更新），不在每個影格重繪 React。
- **邏輯與畫面分離**：`Monster`、`AttackTimer`、`Projectile`、傷害公式不依賴 Three.js，可直接單元測試；`MonsterView`、
  `ProjectileSystem`、`effects` 只負責呈現。最終屬性只由 `systems/stats.ts` 產生（目前是基礎值，Phase 3 / 5 在此加入裝備與等級加成）。
- **裝備是純資料**：`ItemInstance` 只含 uid / 基底 ID / 品質 / 詞綴 ID 與數值，沒有函式或對定義的參照，可直接 JSON 序列化（Phase 5 存檔）。
- **UI 與戰鬥共用同一個屬性公式**：背包提示的比較用 `statsIfEquipped()`，戰鬥用 `computeStats()`，兩者呼叫同一份邏輯。
- **攻擊的一致性**：動畫長度 = 揮擊時間；傷害只在斬擊影格結算一次；冷卻從揮擊開始計時且不短於揮擊本身。怪物同樣如此。
- **TypeScript 7.0.2**：目前 npm 上的最新穩定版（原生編譯器）；`tsc` 僅用於型別檢查，打包由 Vite 處理。

| 通過門口 / 走廊 | （同上，WASD 實測）貼牆滑行進入走廊並抵達下一個房間 |
| 深度排序 | 角色在箱子北側（後方）時被箱子遮住下半身；在南側（前方）時蓋住箱子（已截圖檢視） |
| 左鍵點擊 / 按住移動 | 點擊走到目標（含同一影格內按下又放開的快速點擊）；按住並拖曳游標時角色跟隨；點到牆 / 箱子後會停在障礙前 |
| 右鍵與 QWERT | 右鍵與 Q、W、E、R、T 各自顯示對應的「尚未實作」提示；右鍵不會移動角色；WASD 不再移動角色 |
| 素材載入失敗 | 刻意指向不存在的 PNG：顯示警告、使用佔位圖、遊戲正常運作（驗證後已還原） |
| 視窗縮放 | 1280×720 → 900×600 → 1920×1080：canvas 尺寸跟隨，畫面不變形（腳本實測 + 截圖） |
| 開發模式（React StrictMode 重複掛載 / 卸載） | DOM 內只剩 1 個 canvas，無 console 錯誤或警告 |

**尚未驗證 / 已知限制**

- 只在 Edge（Chromium）測過；Firefox / Safari 未測。
- 沒有真實 GPU 上的效能測試（headless 軟體渲染下約 90 FPS）。
- 角色目前只有單一朝向（以水平翻轉模擬左右），沒有八方向動畫。
- 瀏覽器端的流程（Game 類別、渲染、輸入、縮放）沒有納入專案的自動化測試，只做過上述一次性的腳本實測
  （Playwright 腳本放在專案外，未提交）；專案內的單元測試只涵蓋純邏輯。
- 沒有測試過長時間遊玩的記憶體變化（目前沒有動態生成物件，風險低，但未量測）。

## 人工驗收步驟

### Phase 5（第一章完整流程）

1. 開新遊戲，依序：岩牙（接任務、林道殺 5 隻、回報）→ 汐（先打招呼，再談一次接任務）→ 源泉洞（擊敗菁英、走到水池南岸點「發光的碎片」）→ 回報汐 → 祈漪（遞碎片、接任務）→ 初胎遺跡（擊敗守衛、點「初胎之印」）→ 回報祈漪 → 祈漪（接任務 4）→ 村子南邊的路（現在通了）到海岸 → 找老舵談話 → 點「擱淺的渡船」選「登上渡船」。
2. 想快速測試：按 F3 → F9 升級、F10 開封石與海岸路、F6 穿上傳奇再打 Boss。
3. 章節結束畫面按「回到島上繼續探索」可繼續走動。

### Phase 5（任務系統）

1. 在胎息村，岩牙頭上有黃色的 `!`。和岩牙對話，連續按 Enter，最後在「好，我去。」選項按 1（或點選）：出現「任務開始：初試鋒芒」，左上角出現任務追蹤，`!` 消失。
2. 按 `J` 看任務紀錄，Esc 關閉。
3. 往東走進符文地板到臍帶林道，打死 5 隻怪：每殺一隻提示進度，第 5 隻時顯示「任務可交付」，追蹤變成「回報岩牙」。
4. 回到村子，岩牙頭上變成綠色的 `?`。和岩牙對話：任務完成、背包多一件魔法裝備、獲得經驗。再按 `J`，任務在「已完成」。

### Phase 5（NPC 與對話）

1. 在胎息村，四個人物站在地上，頭上有綠色名牌（祈漪／村長、岩牙／獵人、汐／汲水人、老舵／船匠）。
2. 點祈漪的名牌（或直接點祈漪本人）：角色走過去，下方出現對話框。按 Enter 或點擊繼續；出現選項時按 1 / 2 / 3 或點選項。
3. 對話結束後再找祈漪：換成另一段對話。如果已經認識汐，祈漪多一個「您認識汐嗎？」的選項。
4. 對話中試著按 Q、I、右鍵、Space：都沒有反應。按 Esc 離開。
5. 試著走過 NPC：會被擋住。

### Phase 5（多地圖與傳送門）

1. 開新遊戲：出現在「胎息村」，沒有怪物。按 F3 看得到青綠色的傳送門與入口標記；村子東邊地上有一排符文地板。
2. 走進東邊的符文地板：畫面淡出再淡入，來到「臍帶林道」，站在西側。背包、等級、血量都還在。
3. 往林道最東邊走：走進符文地板只會顯示「封石紋絲不動。」。按 F3 → F10 後再走進去，來到「初胎遺跡」。
4. 在遺跡 Boss 房右下角有回林道的符文地板；林道西側的符文地板回到村子。

### Phase 5（經驗與升級）

1. 看畫面下方血條：下面有「Lv 1」與金色經驗條。打死一隻怪，經驗條增加（屍鬼 +10）。
2. 按 F3 → F9 升一級：角色頭上出現 LEVEL UP、腳下金色光環、血量回滿，經驗條重置並顯示更大的升級需求；按 I 開背包，傷害、最大生命、護甲都比升級前高。
3. 連按 F9 到 Lv 20：經驗條顯示 MAX。死亡後重新開始，等級仍在。

### Phase 4

1. 按 F3 → F6 穿上四件傳奇（建議，初始角色打不過 Boss）。
2. 技能：對著怪物按 Q（身邊一圈光環）、W（金色光矢穿過整排敵人）、E（游標位置爆開並使敵人暈眩）。技能列顯示冷卻倒數，冷卻中重按沒有反應。
   揮擊進行到一半時按技能鍵，揮擊結束後技能會自動施放。R、T 顯示「技能尚未解鎖」。
3. 按 F3 → F8 傳送到菁英區：兩隻體型較大的怪，頭上有金色名牌（菁英 · 名稱 / 詞綴）。注意「閃電」詞綴的攻擊會多一道電弧與第二次傷害、「吸血」詞綴的怪被打時血量會回升。擊殺後掉 2 件裝備。
4. 再按一次 F8 傳送到 Boss 房：Boss 發現你後，上方出現紫色血條與階段刻度。
   - 看地面出現紅色圓圈預警，約 1.2 秒後爆發——在爆發前離開圈外，或按 Space 閃避（無敵）就不會受傷
   - 把 Boss 打到 66% 以下：出現「進入第 2 階段」，開始向你射出 5 連扇形彈幕；33% 以下進入第 3 階段，彈幕變 9 連、動作更快
   - 對 Boss 使用 E（暈眩）：沒有效果，Boss 也不會被打出硬直
5. 擊敗 Boss：掉出 4 件以上裝備（至少 1 件稀有以上），畫面顯示「Boss 已被擊敗」，可以撿完戰利品；按 F7 或死亡後按重新開始會讓 Boss 重生。

### Phase 3

1. `npm run dev`，按 F3 開啟除錯模式，再按 F4：腳邊掉出多件裝備，每件上方有名稱標籤（顏色代表品質：白 / 藍 / 黃 / 橘），腳下有同色光圈。
2. 點擊一個名稱標籤：角色走過去撿起，底部提示「拾取：xxx」；按 F 撿起身邊最近的一件。
3. 按 I 開啟背包：左側是五個裝備欄與角色屬性，右側是 30 格背包。懸停物品：顯示詞綴，並與已裝備的同部位物品比較（綠 ▲ 變強、紅 ▼ 變弱）。
4. 左鍵點擊背包裡的武器：裝備上，舊武器回到背包，左側「攻擊力」立刻改變；對怪物揮擊，傷害數字也隨之改變。點擊裝備欄中的物品可卸下。
5. 右鍵點擊背包物品：丟到腳邊，可再撿起。
6. 撿滿 30 格後再撿一件：提示「背包已滿！」，背包內容不變，物品仍在地上。
7. **快速測試傳奇**：按 F3 → F6 直接穿上全部 4 件傳奇（或 F4 掉落後自己撿來換）；F7 隨時回滿血並重生怪物。效果觀察方式：
   - 雷霆裁決：對怪物群揮擊，約每 4 次出現一次藍色閃電，連跳最多 3 隻
   - 深淵之心：把血打掉一些後擊殺怪物，頭上跳出綠色「+數字」（最大生命的 6%）
   - 神墜之靴：按 Space，血條上方出現「疾行」徽章並持續 2 秒，移動明顯變快
   - 殞星指環：擊殺怪物後出現「狂熱」徽章並持續 3 秒，揮擊明顯變快

8. 按 Space：角色朝游標方向快速衝刺，衝刺時被攻擊不會受傷。
9. 殺死怪物：約一半會掉裝備；死亡後按「重新開始」，背包與裝備仍保留。

### Phase 2

1. `npm run dev`，在起始房按右鍵：角色舉劍揮出扇形劍氣；按住右鍵會連續揮擊；揮擊時角色不會移動。
2. 走進東側走廊後的第一個房間（點擊走過去）。怪物看到你就會追來：屍鬼貼身揮爪、獵犬衝刺、祭影站遠處發射紫色光球。
3. 被打到時畫面邊緣閃紅光、頭上跳出紅色負數；底部血條下降。
4. 對怪物按右鍵：頭上跳出白色傷害（暴擊為較大的金色數字），怪物頭上出現血條；怪物被打到會短暫硬直，打死後倒地並淡出。
5. 殺死所有怪物：畫面顯示「區域已清空！」，頂部計數變成「剩餘 0 / 9」。
6. 離開怪物視線超過一段時間，怪物會放棄並走回出生點；站在牆的另一側時怪物不會看見你。
7. 讓怪物把你打死：出現「你已倒下」，怪物停止攻擊，右鍵無效；按「重新開始」回到起點、血量回滿、怪物重新出現。
8. 在安全處等 5 秒以上，血量會緩慢回復。
9. `npm run build && npm run preview`：行為一致。

### Phase 1

1. `npm install && npm run dev`，開啟顯示的網址。看到載入畫面後進入深色地城，左上顯示「神墜 · 墮神遺跡」。
2. 在地板上按左鍵：角色走過去，目標處出現金色標記，抵達後回到待機動畫；按住左鍵並移動游標：角色持續跟隨。右鍵與 Q W E R T：畫面下方短暫出現「尚未實作」提示，角色不動。
3. 點擊牆壁方向或牆外：角色停在牆前，不會穿牆。
4. 點擊箱子後方：角色停在箱子前，不會穿過；點擊旁邊空地可繞過。
5. 繞到箱子「後方」（螢幕上方）：箱子遮住角色下半身。繞到「前方」：角色蓋住箱子。
6. 按 F3：顯示紅色牆碰撞框、橘色箱子框、藍 / 紫色出生點、綠色角色碰撞圈，右上顯示 FPS 與座標。
7. 點擊起始房東側門口外的走廊，一路點擊進入下一個房間；鏡頭平滑跟隨。
8. 縮放瀏覽器視窗：畫面不變形、鏡頭仍置中於角色。
9. `npm run build && npm run preview`：行為一致。

## 資料保存

存檔功能將於 Phase 5 加入，使用 `localStorage`。屆時請注意：存檔只存在**目前瀏覽器、目前網站來源**，
清除瀏覽器資料或換瀏覽器 / 網址都會導致存檔遺失。
