# 神墜 Divine Fall

單人 2.5D 等角視角刷寶 ARPG（Three.js + TypeScript + Vite + React）。

> 世界曾由古老神祇統治。一場名為「神墜」的災變讓神明隕落，神性碎片散落各處……

**目前進度：Phase 2 / 6（戰鬥與怪物）。** 可以在地城裡移動、與怪物戰鬥、被擊倒並重新開始；
但掉寶、背包、裝備、技能、Boss、成長與存檔都**尚未實作**，還不是完整的遊戲。下方「開發進度」逐項標示實際狀態。

## 快速開始

需要 Node.js 20+（開發環境為 Node 24）。

```bash
npm install
npm run dev        # 開發伺服器
npm run typecheck  # TypeScript 型別檢查
npm test           # Vitest 單元測試
npm run build      # 型別檢查 + production build（輸出到 dist/）
npm run preview    # 預覽 production build
```

## 操作

| 輸入 | 功能 | 狀態 |
| --- | --- | --- |
| 左鍵（點擊 / 按住） | 走到點擊位置；按住則持續朝游標移動，地面會顯示金色標記 | ✅ |
| 右鍵（點擊 / 按住） | 朝游標方向揮擊，按住則連續揮擊。揮擊時角色會停在原地，且右鍵優先於左鍵移動 | ✅ |
| Q / W / E / R / T | 技能 1–5 | ⏳ 已綁定，按下只會顯示「尚未實作」提示（Phase 4 實作） |
| 死亡畫面的「重新開始」按鈕 | 回到起點、血量回滿、怪物重新生成 | ✅ |
| F3 | 顯示碰撞輪廓、出生點、FPS 與座標 | ✅ |
| Space、I / B、F、Esc | 閃避、背包、拾取、暫停 | ⏳ 鍵位已在設定檔保留，尚未實作 |

鍵位集中在 [src/config/gameConfig.ts](src/config/gameConfig.ts)：鍵盤用 `KEYBINDINGS`（`KeyboardEvent.code`），滑鼠用 `MOUSE_BINDINGS`（0 左鍵 / 2 右鍵）。
移動只用滑鼠，因此 W 不再是移動鍵，WASD 不會移動角色。技能暫定 5 個（QWERT），最終數量於 Phase 4 決定。

```

```

後續階段會依需要新增 `data/`（items、affixes…）、`systems/`（Loot、Inventory…）、`storage/`。

## 重要設計決策

- **座標**：世界座標為格子單位（1 單位 = 1 格），+x 朝螢幕右下、+y 朝螢幕左下。圖塊為 64×32 的 2:1 菱形。
  遊戲邏輯只用世界座標，只有渲染時才投影到畫面。
- **深度排序**：所有材質關閉 depth test，順序完全由 `renderOrder = 圖層 × 1,000,000 + (x+y) × 100` 決定，
  其中 x、y 為精靈**腳底**的世界座標。圖層：地板 < 地面裝飾（陰影、出口）< 物件（牆、箱子、角色）< 前景。
- **碰撞獨立於圖片**：只由 `MapData` 的牆格與箱子足跡決定。移動以小步長前進後推出重疊，自然得到貼牆滑行。
- **佔位美術**：Phase 1 的圖像全部由程式即時繪製，避免在授權未確認前引入外部素材。替換方式與授權清單見 [ASSETS.md](ASSETS.md)。
- **Vite `base: './'`**：所有 URL 為相對路徑，同一份 build 可放在網站根目錄或 GitHub Pages 子路徑（`/<repo>/`）。
  執行期資源（地圖、素材）透過 `assetUrl()` 加上 base。
- **React 只負責 UI**：Game 以 `useSyncExternalStore` 對外發佈不可變快照（約每 0.25 秒更新），不在每個影格重繪 React。
- **邏輯與畫面分離**：`Monster`、`AttackTimer`、`Projectile`、傷害公式不依賴 Three.js，可直接單元測試；`MonsterView`、
  `ProjectileSystem`、`effects` 只負責呈現。最終屬性只由 `systems/stats.ts` 產生（目前是基礎值，Phase 3 / 5 在此加入裝備與等級加成）。
- **攻擊的一致性**：動畫長度 = 揮擊時間；傷害只在斬擊影格結算一次；冷卻從揮擊開始計時且不短於揮擊本身。怪物同樣如此。
- **TypeScript 7.0.2**：目前 npm 上的最新穩定版（原生編譯器）；`tsc` 僅用於型別檢查，打包由 Vite 處理。

## 人工驗收步驟

### Phase 2

1. `npm run dev`，在起始房按右鍵：角色舉劍揮出扇形劍氣；按住右鍵會連續揮擊；揮擊時角色不會移動。
2. 走進東側走廊後的第一個房間（點擊走過去）。怪物看到你就會追來：屍鬼貼身揮爪、獵犬衝刺、祭影站遠處發射紫色光球。
3. 被打到時畫面邊緣閃紅光、頭上跳出紅色負數；底部血條下降。
4. 對怪物按右鍵：頭上跳出白色傷害（暴擊為較大的金色數字），怪物頭上出現血條；怪物被打到會短暫硬直，打死後倒地並淡出。
5. 殺死所有怪物：畫面顯示「區域已清空！」，頂部計數變成「剩餘 0 / 9」。
6. 離開怪物視線超過一段時間，怪物會放棄並走回出生點；站在牆的另一側時怪物不會看見你。
7. 讓怪物把你打死：出現「你已倒下」，怪物停止攻擊，右鍵無效；按「重新開始」回到起點、血量回滿、怪物重新出現。
8. 在安全處等 5 秒以上，血量會緩慢回復。
9. `npm run build && npm run preview`：行為一致。

### Phase 1

1. `npm install && npm run dev`，開啟顯示的網址。看到載入畫面後進入深色地城，左上顯示「神墜 · 墮神遺跡」。
2. 在地板上按左鍵：角色走過去，目標處出現金色標記，抵達後回到待機動畫；按住左鍵並移動游標：角色持續跟隨。右鍵與 Q W E R T：畫面下方短暫出現「尚未實作」提示，角色不動。
3. 點擊牆壁方向或牆外：角色停在牆前，不會穿牆。
4. 點擊箱子後方：角色停在箱子前，不會穿過；點擊旁邊空地可繞過。
5. 繞到箱子「後方」（螢幕上方）：箱子遮住角色下半身。繞到「前方」：角色蓋住箱子。
6. 按 F3：顯示紅色牆碰撞框、橘色箱子框、藍 / 紫色出生點、綠色角色碰撞圈，右上顯示 FPS 與座標。
7. 點擊起始房東側門口外的走廊，一路點擊進入下一個房間；鏡頭平滑跟隨。
8. 縮放瀏覽器視窗：畫面不變形、鏡頭仍置中於角色。
9. `npm run build && npm run preview`：行為一致。
